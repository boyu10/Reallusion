🔄 架構師「2 換 2」優化處方

將評估分數從 75 分直接拉至 95 分的關鍵調整：釋出 2 個無效/重複槽位，換進 2 個高回報決定論防線。

#97447 下嘴唇內部爛掉

問題本質：視覺美術與 Morph 權重。GPU 收到合法座標無例外拋出。若用截圖比對易因抗鋸齒假警報；人工看 3 秒即可判定，自動化代價過高。

#96459 Refine Mesh 幾何不一致

遞補理由：Apply -> Undo -> Apply 造成頂點座標微漂移。人眼看不出，自動化用 Vertex MD5 Hash 5 毫秒精準捕捉！

🔄 建議合併槽位 2 SWAP 2 ✅ 推薦遞補 (狀態機防線)
#97792 Re-project New Project Crash

問題本質：與 #97732 根本是同一記憶體野指標（Dangling Pointer）釋放缺陷，應併入同個生命週期測試，佔用獨立名額屬冗餘。

#97746 Front/Side 切換後點擊崩潰

遞補理由：Refine Mesh 模態視窗在 Front 與 Side 分頁切換時，內部狀態機按鈕 Callback 脫節引發空指標。防禦 UI 狀態機序列脫節的黃金案例。
